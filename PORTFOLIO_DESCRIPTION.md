# Portfolio description

## Español

**LeadFlow — CRM para freelancers y pequeñas empresas**

Proyecto personal de demostración que reúne prospectos, oportunidades y próximos pasos en una interfaz SaaS con identidad propia. Incluye registro e inicio de sesión, datos aislados por usuario, tabla con búsqueda y filtros, pipeline Kanban con arrastre, notas, tareas con vencimientos, historial y dashboard comercial calculado desde PostgreSQL.

La importación CSV permite asignar columnas, revisar errores y duplicados y confirmar la carga; la exportación incluye protección frente a fórmulas de planilla. Una demo opcional añade datos completamente ficticios solo a espacios vacíos, sin sobrescribir trabajo.

Desarrollado con React, TypeScript, FastAPI, SQLAlchemy y PostgreSQL. Verificación local: 183 pruebas backend, 34 frontend y tres recorridos reales de Chromium. Se revisaron teclado y pantallas de 320 a 1440 píxeles.

Este proyecto muestra capacidades de desarrollo full-stack y preparación de una demo técnica. **No representa trabajo para un cliente real ni resultados comerciales medidos.** Funciona localmente; no está desplegado como servicio público.

Versión breve para Workana, Upwork o portafolio: “CRM de demostración con React, TypeScript, FastAPI y PostgreSQL: pipeline Kanban, seguimiento comercial, métricas y CSV validado, con aislamiento por usuario y pruebas de integración.”

## English

**LeadFlow — CRM for freelancers and small businesses**

A personal portfolio demonstration that brings leads, opportunities and next actions into a focused SaaS interface with its own visual identity. Features include registration/session authentication, isolated user workspaces, searchable/filterable lead tables, a draggable Kanban pipeline, notes, dated follow-ups, activity history and a PostgreSQL-backed sales dashboard.

CSV import supports column mapping, row validation, duplicate reporting and explicit confirmation. Export neutralizes spreadsheet formula-like values. An opt-in fictional demo populates empty workspaces without overwriting existing work.

Built with React, TypeScript, FastAPI, SQLAlchemy and PostgreSQL. Local verification: 183 backend tests, 34 frontend tests and three real Chromium journeys, with keyboard/responsive review from 320 to 1440 pixels.

This project demonstrates full-stack implementation and technical demo preparation. **It is not commissioned client work and makes no measured business-outcome claims.** It runs locally and is not deployed as a public service.

Short listing: “Full-stack CRM demonstration using React, TypeScript, FastAPI and PostgreSQL, with a Kanban pipeline, dated follow-ups, sales metrics, validated CSV transfer, user isolation and integration tests.”
